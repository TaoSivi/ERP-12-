# LaoBooks ERP

ໂປແກມ ERP ສຳລັບ SME ລາວ — 12 ໂມດູນ, ບັນຊີຄູ່ (double-entry) ອັດຕະໂນມັດ, VAT, FIFO, ເງິນເດືອນຕາມກົດໝາຍລາວ (PIT/LSSO).
ໜ້າຕ່າງ static (HTML/JS) — host ໄດ້ໃນ **GitHub Pages** — ເກັບຂໍ້ມູນໃນ **Google Sheet** ຜ່ານ Google Apps Script.

> ✅ ເປີດໃຊ້ໄດ້ທັນທີໃນ **Demo Mode** (ເກັບຂໍ້ມູນໃນ browser) — ບໍ່ຕ້ອງຕັ້ງຄ່າຫຍັງ. ພ້ອມເຊື່ອມ Google Sheet ເມື່ອຕ້ອງການ.

---

## 1) ລອງໃຊ້ທັນທີ (Demo Mode)

ເປີດໄຟລ໌ `index.html` ດ້ວຍ browser (double-click) ຫຼື ຮັນ local server:

```bash
cd erp-app
python -m http.server 8080
# ເປີດ http://localhost:8080
```

ຂໍ້ມູນຈະຖືກເກັບໃນ browser (localStorage). ມີຂໍ້ມູນຕົວຢ່າງໃຫ້ພ້ອມ.

---

## 2) Deploy ຂຶ້ນ GitHub Pages (ໜ້າຕ່າງ online)

1. ສ້າງ repository ໃໝ່ໃນ GitHub → upload ໂຟເດີ `erp-app` (ຫຼື push ດ້ວຍ git).
2. ໄປ **Settings → Pages** → Source = `Deploy from a branch` → Branch = `main` / folder = `/root` (ຫຼື `/erp-app`).
3. ລໍ 1–2 ນາທີ → ໄດ້ link ເຊັ່ນ `https://<user>.github.io/<repo>/`.

> ຖ້າວາງໄຟລ໌ໃນ subfolder `erp-app`, ໃຫ້ຕັ້ງ Pages folder ເປັນ root ຂອງ repo ແລ້ວເຂົ້າ `.../erp-app/`.

---

## 3) ເຊື່ອມ Google Sheet (ເກັບຂໍ້ມູນຖາວອນ)

### ຂັ້ນຕອນ

1. ສ້າງ **Google Sheet** ໃໝ່ (ຕັ້ງຊື່ເຊັ່ນ `LaoBooks DB`).
2. ເມນູ **Extensions → Apps Script**.
3. ລຶບ code ເກົ່າ → ວາງເນື້ອຫາຈາກ `apps-script/Code.gs` ທັງໝົດ → **Save**.
4. (ທາງເລືອກ) ຮັນ function `setupTabs` ໜຶ່ງຄັ້ງ ເພື່ອສ້າງ tab ລ່ວງໜ້າ + ອະນຸຍາດສິດ.
5. ກົດ **Deploy → New deployment**:
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - ກົດ **Deploy** → copy **Web app URL** (ລົງທ້າຍດ້ວຍ `/exec`).
6. ເປີດ `assets/js/config.js` → ວາງ URL ໃສ່:

```js
APPS_SCRIPT_URL: "https://script.google.com/macros/s/AKfy.../exec",
```

7. Refresh ໜ້າ web. ມຸມຊ້າຍລຸ່ມຈະຂຶ້ນ **● Google Sheet** (ສີຂຽວ). ຂໍ້ມູນຈະຖືກຂຽນລົງ Sheet.

### ໝາຍເຫດ
- ແຕ່ລະ tab ໃນ Sheet = ໜຶ່ງຕາຕະລາງ (customers, invoices, journal_entries, ...). ແຖວທຳອິດ = ຫົວຖັນ.
- ຖ້າແກ້ code ໃນ Apps Script ໃໝ່ ຕ້ອງ **Deploy → Manage deployments → Edit → New version**.
- ຖ້າພົບ error CORS: ກວດວ່າ deploy ເປັນ **Anyone** ແລະ URL ລົງທ້າຍ `/exec` (ບໍ່ແມ່ນ `/dev`).

```
│  └─ js/
│     ├─ config.js          ⚙️ ຕັ້ງຄ່າ (ໃສ່ Apps Script URL ທີ່ນີ້)
│     ├─ store.js           ຊັ້ນຂໍ້ມູນ (Demo + Cloud)
│     ├─ accounting.js      Engine ບັນຊີ (JE, VAT, FIFO, PIT)

├─ apps-script/Code.gs      Backend Google Sheet
└─ README.md
```
